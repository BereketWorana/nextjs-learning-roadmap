# Full-Stack Learning Plan: Next.js + NestJS

## 1. Learning Goal

Over eight weeks, I will study Next.js and NestJS together to develop practical full-stack development skills.

- **Next.js:** Frontend development, routing, rendering, data fetching, forms, authentication, and optimization.
- **NestJS:** Backend architecture, REST APIs, dependency injection, validation, databases, authentication, and testing.

## 2. Weekly Study Schedule

| Week | Next.js | NestJS | Combined Outcome |
|---|---|---|---|
| 1 | Introduction, React relationship, rendering models, project setup | Introduction, Node.js and TypeScript refresher, architecture, modules, controllers, providers | Understand both frameworks |
| 2 | Routing, nested routes, layouts, dynamic routes | Controllers, HTTP methods, routing, parameters, status codes | Build frontend pages and API endpoints |
| 3 | Server and Client Components | Providers, services, dependency injection, feature modules | Separate UI and business logic |
| 4 | Data fetching, caching, revalidation, loading states | DTOs, validation, pipes, exception handling | Fetch and validate data |
| 5 | Forms, Server Actions, Route Handlers, Zod | Database integration, ORM, migrations | Build CRUD functionality |
| 6 | Styling, optimization, SEO, accessibility | Authentication, authorization, JWT, guards | Build a polished and secure application |
| 7 | Authentication, sessions, protected routes | Request pipeline, Swagger, unit and E2E testing | Secure and document the application |
| 8 | API integration, state management, testing, deployment | Integration, testing, deployment | Complete a full-stack application |

## 3. Weekly Workload

- Next.js: approximately 6–8 hours per week.
- NestJS: approximately 6–8 hours per week.
- Combined: approximately 12–16 hours per week.

The workload will be distributed across the week according to the learning tasks.

## 4. Learning Method

Each topic will follow this process:

1. Understand the concept and its purpose.
2. Study how it works through practical examples.
3. Implement the concept independently.
4. Test the implementation and troubleshoot errors.
5. Document what was learned.

At the end of each week, I will update the checklist and prepare a separate report for each framework.

The reports will document topics studied, practical work, key concepts, challenges and solutions, questions, and the following week's plan.
