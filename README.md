# Next.js Learning Roadmap

## Overview

This repository documents my practical learning journey with Next.js over an eight-week period. The goal is to develop a strong understanding of modern frontend development using Next.js, React, TypeScript, and Tailwind CSS.

## Learning Objectives

- Understand Next.js architecture and the App Router.
- Work with layouts, pages, and navigation.
- Understand Server and Client Components.
- Implement data fetching and caching.
- Build forms and handle user interactions.
- Apply authentication and authorization concepts.
- Improve application performance and SEO.
- Test and deploy a Next.js application.

## Development Setup

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Available Scripts

| Command | Purpose |
|---|---|
| `npm run dev` | Start development server |
| `npm run build` | Create production build |
| `npm run start` | Run production server |
| `npm run lint` | Check code using ESLint |
